# 릴스가 AI처럼 안 보이게 하는 체크리스트

효과가 큰 순서입니다.

## 촬영
- [ ] 앵글 2개(정면 + 측면/클로즈) 또는 4K 촬영
- [ ] 휴대폰으로 인서트 3~5개 (화면 스크롤, 키보드, 필기, 실제 결과물)
- [ ] 숫자를 말하는 장면이 있으면 그 숫자가 보이는 실제 화면을 녹화

## 그래픽
- [ ] 지어낸 UI·수치 대신 **실제 화면** (본인 대시보드, 실제 템플릿, 실제 댓글)
- [ ] 그래픽은 장면당 하나. 아무것도 없는 구간을 남긴다
- [ ] 모든 요소가 같은 방식으로 튀어나오지 않게 (등장 방식 3~4종을 섞기)
- [ ] 착지한 제목은 움직이지 않는다 (둥둥 떠다니는 루프 금지)

## 컷·줌
- [ ] 하드컷은 25% 이상 차이, 문장 경계에서만 ([camera-rules.md](camera-rules.md))
- [ ] 눈높이가 컷마다 오르내리지 않는다
- [ ] 무음을 전부 자르지 않는다 (숨, 잔향을 남긴다)

## 자막
- [ ] 받아쓰기 오타를 직접 교정
- [ ] 말투 그대로 (문어체로 다듬지 않기)
- [ ] 강조는 영상 하나에 3~4번 이하

## 색
- [ ] LUT 강도 60~70%
- [ ] 피부톤이 원본보다 노랗거나 붉지 않은지
- [ ] 그레인은 아주 약하게 (0.05 안팎)

## 소리
- [ ] 효과음은 2~3번 (그래픽 등장할 때만)
- [ ] 배경음악은 목소리 아래 (-14 LUFS 완성본 기준 배경음악 볼륨 0.1~0.15)
- [ ] 레퍼런스 음원은 쓰지 않는다
