# B롤 계획 양식 (B-Roll Finder 방법론)

원칙 ([b-roll-finder](https://github.com/louisedesadeleer/b-roll-finder) SKILL.md 요약):
- **최종 선택은 사람이 한다.** 도구는 후보를 좁힌다.
- **말의 의미를 보여 준다**, 단어를 보여 주지 않는다.
- 숫자·통계 → 그 숫자가 보이는 화면. 사용법 → 화면 녹화. 본인 콘텐츠 → 본인 것.
- 맞는 소재가 없으면 비워 둔다. 틀린 B롤보다 없는 게 낫다.
- 설명형 영상은 B롤 비율 20~30%.
